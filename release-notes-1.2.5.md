# Sky Vanguard 1.2.5

- Added built-in startup update checks with `Update now`, `Later`, and `Skip this version`
- Added an in-match pause menu with `Resume` and `Return to Menu`
- Added persistent local combat stats for `Vs AI`, `Vs Human > Player 1`, and `Vs Human > Player 2`
- Added a richer end-of-match debrief with winner callouts, aircraft used, kills, and accuracy for both sides
- Preserved the Skytrace Studios branding pass while keeping Sky Vanguard as the primary identity
